# Spiking Neural Network Analysis
Spiking Neural Network (SNN) analysis using NEST.<br>
Results published in the poster presented at NEST 2026 Conference:

    Statistics of Spiking Neural Networks
    Based on Counting Process
    by
    Alexander Dimitrov, Anne-Marie Greggs, Gina Healy

**Note:**
Some of the images in the poster were generated by earlier work done by Anne-Marie Greggs using Brian2. The link to her work is:
https://github.com/Epsibee/Brian2-Poisson-Point-Process/

Additional spectral analysis work can be found here, however those results are not yet published.

## Development Platform
- Ubuntu 24.04 (for which a Python Package Installer for NEST exists)
- Python 3.12.3
- NEST 3.10.0

## Virtual Environment Prereqs
- NEST
- NumPy
- SciPy
- Matplotlib
- Pandas
